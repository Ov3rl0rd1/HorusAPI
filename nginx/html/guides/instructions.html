Подходит для iPhone и iPad. Ставится из App Store, отдельной регистрации не требует.

  1. Установите Streisand из App Store и откройте приложение.
  2. Скопируйте свою ссылку подписки: {{ссылка}}
  3. В Streisand нажмите + в правом верхнем углу и выберите Добавить из буфера обмена.
  4. Вернитесь на главный экран, выберите появившийся профиль Horus VPN и нажмите большую кнопку подключения.
  5. При первом запуске iOS попросит разрешить добавление конфигурации VPN — нажмите Разрешить и введите код-пароль устройства.

Готово. В строке состояния появится значок VPN. Чтобы отключиться, нажмите ту же кнопку ещё раз.

Альтернатива Streisand. Иконки у этого блока нет — вместо неё показывается буква названия.

  1. Скопируйте ссылку подписки: {{ссылка}}
  2. Откройте Shadowrocket — приложение само предложит добавить конфигурацию из буфера обмена. Нажмите Да.
  3. Если предложения не было, нажмите + вверху справа и вставьте ссылку в поле URL.
  4. Выберите профиль в списке и переведите переключатель вверху экрана в положение «включено».

Если приложение Horus для Android установить не получается, подойдёт любой клиент с поддержкой Hysteria2.

  1. Скачайте APK по кнопке выше и установите его. Android спросит разрешение на установку из этого источника — подтвердите.
  2. Скопируйте ссылку подписки: {{ссылка}}
  3. Откройте NekoBox, нажмите + → Импорт из буфера обмена.
  4. Нажмите на профиль Horus VPN, затем кнопку запуска в правом нижнем углу.
  5. Разрешите создание VPN-подключения в системном запросе Android.

Обычно на Windows проще поставить приложение Horus. Этот способ — для случаев, когда установка недоступна.

  1. Скачайте архив, распакуйте в любую папку и запустите nekoray.exe.
  2. Скопируйте ссылку подписки: {{ссылка}}
  3. В меню Программа выберите Добавить профиль из буфера обмена.
  4. Выделите профиль в списке и нажмите Enter, чтобы подключиться.
  5. Включите Режим системного прокси в правом нижнем углу — трафик пойдёт через выбранный сервер.
