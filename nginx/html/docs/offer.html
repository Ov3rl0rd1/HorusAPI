1. Общие положения

1.1. Настоящий документ — публичная оферта на оказание услуг сервиса Horus VPN (далее — «Сервис»). Оформление подписки означает согласие с условиями оферты в полном объёме.

2.1. Исполнитель предоставляет Заказчику доступ к серверам Сервиса для установления защищённого шифрованного соединения (VPN) на срок оплаченной подписки.

2.2. Услуга оказывается дистанционно: через приложение Horus для Windows и Android либо через подключение из браузера на сайте.

2.3. Услуга носит нематериальный характер и считается оказанной с момента предоставления доступа.

3. Что входит в подписку

  • Шифрование трафика и скрытие IP-адреса устройства.
  • Одновременное использование до 5 устройств на одну подписку.
  • Выбор локации сервера вручную или автоматически.
  • Все функции приложения без дополнительной оплаты.
