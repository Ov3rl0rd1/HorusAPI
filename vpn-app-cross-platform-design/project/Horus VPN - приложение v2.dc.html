HORUS VPN — приложение
Кроссплатформенный дизайн · Windows + Android · тёмная тема · русский язык
Интерактивный прототип — всё кликается Готово к переносу в .NET MAUI / XAML Акцент и цены — в панели Tweaks
Допущения: стиль взят с лендинга Horus (тёмный фиолетовый, золото, Unbounded + Manrope); все элементы соответствуют стандартным MAUI-контролам (Shell, Switch, CollectionView, Border) — переносится в XAML без потерь. Приложение платное — бесплатной версии и пробного периода нет: без активной подписки VPN не включится. Windows открывается на экране входа, телефон — с онбординга; есть регистрация с подтверждением email, сброс пароля и оплата подписки. Дальше: XAML-экспорт, iOS-версия, светлая тема.
