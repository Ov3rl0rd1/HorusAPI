# Инструкция для Claude Design — обновить страницу подключения

Изменился формат ответа API, от которого зависит страница **/connect** (кабинетная
страница «получить ключи»). Ниже — что именно поменять. Логика в нашем репозитории уже
поправлена ([nginx/html/js/connect.js](../nginx/html/js/connect.js),
[nginx/html/js/endpoints.js](../nginx/html/js/endpoints.js)) — приведи свою версию к тому же
контракту.

## Что изменилось в API

**Было:** `GET /servers/connect` → `{ "VLESS": "vless://…", "HY2": "hysteria2://…" }`.

**Стало:** `GET /servers/connect` (с заголовком `X-Session-Key`, как и раньше) →
```json
{
  "server":    { "id": 12, "name": "Germany 1", "country": "DE", "city": "Frankfurt", "host": "de1.example.com" },
  "vless":     [ "vless://…#Horus-DE · VLESS" ],
  "hysteria2":   "hysteria2://…#Horus-DE · HY2",
  "olcrtc":    { "provider": "…", "…": "…" }
}
```

- `vless` — **массив** (сейчас один элемент). Показывай первый валидный (`vless://…`).
- `hysteria2` — строка.
- `olcrtc` — **только для приложения; на сайте игнорировать** (браузер по нему не подключается).
- Пути и метод те же (`GET /servers/connect`), заголовок сессии тот же.

## Что сделать на странице /connect

1. **Парсинг ссылок.** Раньше читались ключи `HY2`/`VLESS`. Теперь:
   - hysteria2 → `resp.hysteria2` (строка);
   - vless → первый элемент `resp.vless[]`.
2. **Блок «текущий сервер»** (по желанию): можно показать `resp.server.country` / `city`
   / `name`, чтобы человек видел, к какому узлу привязан.
3. **Коды ошибок:**
   - `403` — подписка неактивна/истекла → экран «Подписка неактивна».
   - `409` (`code: "no_capacity"`) — свободных мест нет → экран «Свободных серверов нет».
     (Раньше для этого был `404`; теперь `409`.)
4. **Подпись кнопки.** Резерв места происходит при покупке, а не здесь — страница просто
   получает ссылки. Замени «Резервируем место…» на «Получаем ссылки…».
5. **Не показывай `olcrtc`.** Это внутренний протокол приложения.

## Опционально: ссылка-подписка для сторонних клиентов

Можно добавить в кабинет «ссылку-подписку» для импорта в сторонние VPN-клиенты
(v2rayN, Hiddify, Streisand):
```
https://<domain>/servers/connect?key=<session>
```
Тот же путь, но сессия идёт в query `?key=` — API отдаёт base64-подписку (vless + hysteria2).
Показывай её как «строку подписки» с кнопкой «Скопировать». **Предупреди пользователя**, что
ссылка личная (в ней ключ сессии) и что «Выйти на других устройствах» её инвалидирует.

## Что НЕ трогать
- Страница `/reset` (сброс пароля) — без изменений.
- Схема авторизации, `/auth/*`, `/whoami` — без изменений.
- Список серверов в кабинете (`GET /servers`) теперь отдаёт `PingCandidate[]` с полями
  `id, country, city, host, current_load, reserved_count, max_clients` (без `name`; если
  нужно имя — используй `host` как запасной вариант).
